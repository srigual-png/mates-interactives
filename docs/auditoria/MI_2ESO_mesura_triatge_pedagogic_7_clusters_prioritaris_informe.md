# Revisió pedagògica inicial de famílies candidates — 2n ESO, Sentit de la mesura

**Estat: proposta d'auditoria, no aprovació de famílies ni reclassificació oficial de nivells.**

## Punt de partida
S'han executat set lots de comprovacions independents de resposta que cobreixen els **128 tipus** de generador, amb **6.200 exercicis contrastats** (oracles aritmètics i criteris contextuals). Aquest resultat acredita la coherència de les mostres amb els oracles implementats, **no** l'adequació pedagògica definitiva. El catàleg existent agrupa provisionalment els 128 tipus i les seves variants en **72 agrupacions de treball**, que no equivalen a 72 famílies certificades.

## Set agrupacions prioritàries contrastades

| ID | Proposta preliminar | Precaució |
|---|---|---|
| ME2-C001 | Distingir una distància a escala del càlcul de la suma de dos trams i l'aplicació posterior de l'escala | Segona variant pot ser N2 sense família nova |
| ME2-C006 | Distingir obtenir una escala 1:n del factor d'ampliació entre figures semblants | Revisar si s'aplica el mateix principi amb representacions diferents |
| ME2-C008 | Comparar proporcionalitat d'ombres amb proporcionalitat de triangles abstracta; separar altura i ombra com a variants candidates | La incògnita diferent no implica automàticament família diferent |
| ME2-C019 | Revisar separadament fórmules d'àrea de paral·lelogram, rombe i trapezi | Una fórmula diferent no garanteix diferència cognitiva suficient |
| ME2-C038 | Agrupar contextualitzacions de la hipotenusa i estudiar per separat la diagonal de quadrat amb aproximació a √2 | Evitar comptar cada context com una família |
| ME2-C058 | Distingir calcular la superfície exterior d'identificar les parelles de cares del desenvolupament pla | L'objectiu espacial pot ser diferent del procediment numèric |
| ME2-C065 | Distingir la conversió directa volum–capacitat de reconèixer igualtats correctes | Poden ser dues variants de la mateixa equivalència |

Les set agrupacions revisades contenen **33 membres de tipus o variant**. S'ha contrastat la correspondència dels seus membres amb el catàleg original; **no s'ha canviat el recompte provisional de 72 agrupacions**.

## Criteris de classificació a aplicar

- **N1:** reconeixement d'unitats i magnituds o aplicació directa d'una fórmula o equivalència.
- **N2:** tria del model, operacions encadenades, fórmules inverses o comparació argumentada.
- **N3:** integració de dades i estratègies no rutinàries **dins del currículum de 2n ESO**; no forçar cap mínim numèric.

Abans de considerar una escissió com a família independent cal justificar que la **decisió matemàtica exigida** canvia, no només l'enunciat, els números, les unitats o el context. Cal conservar i examinar les variants de dificultat mixta `unitats:6`, `pitagores:15` i `superficies:17`, sense aprovar automàticament els nivells de cap branca.

## Següent feina

Ampliar l'auditoria pedagògica a les altres agrupacions del catàleg, prioritzant els grups que barregen estratègies i temes. Preparar una matriu de **famílies candidates, variants, prova de diferència cognitiva, nivell proposat i risc d'ambigüitat**, per poder presentar després decisions concretes.
