# Revisió dels 14 vincles de deduplicació matemàtica

**Projecte:** Mates Interactives · 2n ESO · Sentit de la mesura. **Estat:** proposta d'auditoria, no classificació oficial.

## Abast i traçabilitat

El creuament anterior de **131 fitxes de dificultat** i **72 agrupacions provisionals** va identificar **14 vincles matemàtics**. Se n'havien aprofundit 3 d'interagrupació; aquesta fase documenta els **11 restants**, amb el model matemàtic, les diferències cognitives, el nivell candidat de cada membre i el risc pedagògic. Són enllaços de revisió, no 14 autoritzacions de fusió.

## Resultats destacats

| Vincles | Relació pedagògica |
| --- | --- |
| DEDUPE-01 | Diagonals, cables, rampes i escales recolzades comparteixen el càlcul d'**hipotenusa**. La modelització de la figura és una variant de dificultat |
| DEDUPE-03 | Estany i parterre amb camí comparteixen **corona circular** i resta d'àrees |
| DEDUPE-04 | Capsa tancada i cartró comparteixen **superfície exterior d'ortoedre** |
| DEDUPE-05 | Volum de cilindre i capacitat en litres comparteixen **πr²h**; en dm³→L hi ha una equivalència directa |
| DEDUPE-07 | Recuperar altura d'un cilindre és **inversió de V=πr²h** amb diferent context d'unitats |
| DEDUPE-08 | Estimacions de longitud, àrea, capacitat i problemes comparteixen **judici d'ordre de magnitud**, però requereixen referents diferents |
| DEDUPE-09 | Unitats i un problema anomenat «pressupost» comparteixen **conversió de superfície m²→cm²**, sense cap càlcul de cost |
| DEDUPE-10 | Mapa i ruta comparteixen obtenció de **distància real a escala 1:n** |
| DEDUPE-11 | Plànols i segments comparteixen **deducció del denominador de l'escala 1:n** |
| DEDUPE-12 | Arbre o edifici comparteixen **proporció entre alçades i ombres** |
| DEDUPE-14 | **No fusionar** tria d'instrument per tolerància (`estimacio:11`) amb judici de coherència (`estimacio:14`) |

Les altres tres relacions revisades són C030/C042 (àrea exterior menys retall), C050/C061 (desenvolupament lateral del cilindre) i C027/C028/C029 (magnituds diferents en cercle i semicercle). Els seus matisos estan a `MI_2ESO_mesura_3_vincles_transversals_informe.md`.

## Criteris per decidir famílies

Una família no s'ha de crear perquè canvia el context, la unitat de sortida o el dibuix. Tampoc s'ha d'unificar automàticament si canvia el **tipus de magnitud**, la **decisió matemàtica** o la **representació espacial** imprescindible.

Els nivells candidats de cada membre són a `MI_2ESO_mesura_11_vincles_estrategies_restants.json`. Les propostes N1/N2/N3 continuen sense aplicar-se. No s'ha de forçar la quota 5–5–3: tota tasca ha de correspondre al nivell de **2n ESO**.
