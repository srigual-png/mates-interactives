## Criteris (0–2 cadascun)

1. **Novetat d'estratègia:** 0 = procediment conegut; 1 = nova decisió o representació potencial; 2 = independència demostrada.
2. **Independència matemàtica:** 0 = combinació o simplificació; 1 = possible, pendent d'evidència; 2 = diferenciació confirmada amb proves.
3. **Adequació curricular provisional:** 0 = no adequada; 1 = necessita ajust; 2 = plausible per a 2n ESO (no homologació).
4. **Càrrega cognitiva:** 0 = pràctica directa; 1 = diversos passos sense modelització autònoma; 2 = restricció, validació o decisió que podria elevar la dificultat.

**La suma no certifica cap família ni determina el N3.** Els quatre eixos només orienten què mereix més proves.
