# Pendents després de revisar els 20 blocs

La classificació dels cinc sentits dels quatre cursos està revisada. Els cinc blocs de 4t inclouen 624 identificadors: 120 numèrics, 132 de mesura, 129 algebraics, 123 espacials i 120 estocàstics. El commit i la verificació pública més recents consten a publicacio-punt3.json.

1. Crear famílies de dificultat alta legítima on falten i ampliar la varietat. Cal que requereixin planificació o reconstrucció, sense augmentar l’etiqueta de procediments directes. Mesura de 4t té dues versions d’una mateixa família de dues observacions; això no equival a dues famílies independents.
2. Mantenir explícits els buits: els exàmens de tema fan servir la cobertura real. Les quotes globals estrictes es bloquegen quan els temes seleccionats no les poden satisfer. No s’omet cap tema per amagar el buit.
3. Aprofundir els oracles independents, les figures i els errors desats antics. Els oracles i regressions actuals cobreixen casos concrets; no es presenta el mostreig com una demostració exhaustiva.
4. Revisar les portades autònomes pendents i migrar els mapes propis dels formularis de fitxes i les exportacions Word/PDF. Els mapes propis de les fitxes no queden migrats automàticament.

Espacial de 4t conserva dos temes curriculars addicionals a Matemàtiques B, encara que històricament el nom inclogui ampliació. A A continuen sent opcionals. Les quatre ampliacions estocàstiques de contingut Batx es mantenen fora de l’examen ordinari.

El punt 3 continua parcial pel que fa a cobertura, varietat i validació exhaustiva; la classificació dels 20 blocs ja no té cursos pendents.
