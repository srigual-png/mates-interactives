## Proporcionalitat: 11 famílies i 13 destins

P01 reconeix proporcionalitat; P02 aplica el valor unitari (variants de preu, factor i consum); P03 calcula la constant; P04 comprova taules; P05 optimitza producció amb pressupost; P06 interpreta la constant; P07 compara preus; P08 repara una taula; P09 reconstrueix amb una suma; P10 diagnostica errors additius; P11 valora si les dades són suficients.

Els destins `unitari-dos-sentits` i `tarifes-i-constant` complementen P02 i P01/P06: no constitueixen dues famílies addicionals. Es conserven els 13 ancoratges i totes les explicacions, inclosa la taula de 15 combinacions del pressupost. No s’ha afegit una segona còpia d’aquest exemple.
