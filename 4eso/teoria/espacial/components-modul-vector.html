🧮 Bloc 3 · Components i mòdul d’un vector

Les components converteixen un desplaçament geomètric en un parell de nombres. El primer descriu el canvi horitzontal i el segon el canvi vertical. Aquesta traducció permet calcular i raonar amb vectors de manera algebraica.

1 · Idea fonamental

Les components d’un vector indiquen quant ens desplacem horitzontalment i verticalment. Si A=(x₁,y₁) és l’origen i B=(x₂,y₂) l’extrem, les components de AB s’obtenen fent sempre extrem menys origen. A partir de les components, el mòdul es calcula amb el teorema de Pitàgores.

📍 Idea clau. Les components no són les coordenades del punt on està dibuixada la fletxa. Descriuen el canvi entre origen i extrem. Per això dos vectors dibuixats en llocs diferents poden tenir exactament les mateixes components.

2 · Conceptes i relacions clau

• Si A=(x₁,y₁) i B=(x₂,y₂), aleshores AB=(x₂−x₁, y₂−y₁).
• Si A és conegut i u=(a,b), l’extrem és B=(xA+a, yA+b).
• Si B és conegut i u=(a,b), l’origen és A=(xB−a, yB−b).
• Si u=(a,b), el seu mòdul és |u|=√(a²+b²).
• El signe de cada component importa: a<0 indica desplaçament cap a l’esquerra i b<0, cap avall.
• Per comparar mòduls no sempre cal calcular arrels: es poden comparar a²+b² dels dos vectors.

Extrem menys origen

La regla fonamental és AB=(xB−xA, yB−yA). L’ordre és essencial: si invertim els punts obtenim BA, que és el vector oposat.

Interpretació dels signes

Una primera component positiva indica moviment cap a la dreta; negativa, cap a l’esquerra. Una segona component positiva indica moviment cap amunt; negativa, cap avall. El signe no fa que el mòdul sigui negatiu.

Recuperar punts

Si coneixem A i el vector u, l’extrem és A+u. Si coneixem B i u=AB, l’origen és B−u. Aquesta és una aplicació directa de l’equació B=A+u.

Mòdul i Pitàgores

Les components són els catets d’un triangle rectangle associat al vector. Per això |u|=√(a²+b²). Si la suma no és quadrat perfecte, el resultat pot quedar com a radical exacte.

Simplificar radicals

Per simplificar √52 podem escriure 52=4·13 i obtenir 2√13. Quan es demana valor exacte és preferible conservar el radical; si el context demana aproximació, es pot donar un decimal amb precisió indicada.

Comparar longituds sense arrels

Com que l’arrel quadrada és creixent, per saber quin vector té més mòdul n’hi ha prou amb comparar a²+b². Això evita càlculs innecessaris.

3 · Procediment de treball

Quan l’exercici no indica directament el mètode, aquesta seqüència ajuda a ordenar el raonament:

  1. Escriu origen i extrem amb les coordenades ben ordenades.
  2. Resta x final − x inicial i y final − y inicial.
  3. Interpreta els signes per verificar que el desplaçament té sentit.
  4. Per al mòdul, eleva les dues components al quadrat, suma i fes l’arrel.
  5. Simplifica el radical o aproxima només si l’enunciat ho demana.

✏️ Exemple resolt pas a pas

  1. Siguin A=(−2,1) i B=(4,5).
  2. Component horitzontal: 4−(−2)=6.
  3. Component vertical: 5−1=4.
  4. Per tant, AB=(6,4).
  5. El mòdul és |AB|=√(6²+4²)=√52=2√13.

5 · Errors freqüents i com evitar-los

  • Fer origen − extrem i obtenir el vector oposat.
  • Intercanviar component x i component y.
  • Calcular √(a²)+√(b²) en lloc de √(a²+b²).
  • Perdre el signe d’una component abans d’elevar-la al quadrat.
  • Confondre les components amb les coordenades de l’extrem.

Quan cometis un error a la pràctica, torna a identificar exactament quina propietat o pas s’ha aplicat malament. Corregir el procediment és més útil que memoritzar la resposta concreta.

✅ Resum essencial

En acabar aquest tema hauries de poder explicar els conceptes amb paraules pròpies, aplicar les relacions anteriors sense dependre d’un dibuix a escala i justificar els passos d’un problema. Si només recordes una fórmula però no saps quan ni per què s’utilitza, encara convé reforçar la teoria.
