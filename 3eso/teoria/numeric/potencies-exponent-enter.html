Potències d’exponent enter

Exponent zero i negatiu, bases enteres i racionals i propietats de les potències

🟢 Practicar · Guiat🟠 Practicar · AutònomVeure el bloc →

A 3r d’ESO les potències s’amplien als exponents enters: positius, zero i negatius. Les propietats són eines de transformació; cal saber quan es poden aplicar i quan no.

Concepte clau

Base i exponent

aⁿ representa un producte repetit quan n és enter positiu. La base és a i l’exponent indica quantes vegades es multiplica.

2⁴ = 2·2·2·2 = 16
Concepte clau

Exponent zero

a⁰ = 1, si a ≠ 0
L’exponent zero no significa que el resultat sigui 0.
Concepte clau

Exponent negatiu

Un exponent negatiu indica el recíproc; no fa que el resultat sigui necessàriament negatiu.

a⁻ⁿ = 1/aⁿ
(2/3)⁻² = (3/2)² = 9/4
Concepte clau

Propietats amb la mateixa base

aᵐ·aⁿ = aᵐ⁺ⁿ
aᵐ/aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
Concepte clau

Potència d’un producte o quocient

(ab)ⁿ = aⁿbⁿ
(a/b)ⁿ = aⁿ/bⁿ
Concepte clau

Signes i parèntesis

Els parèntesis determinen si el signe forma part de la base.

(−3)² = 9
−3² = −(3²) = −9
Concepte clau

Quan NO es poden aplicar les propietats

aᵐ + aⁿ ≠ aᵐ⁺ⁿ
Les regles de sumar/restar exponents són per a productes i quocients de potències de la mateixa base, no per a sumes de potències.

✏️ Exemples resolts

Exemple resolt

Producte amb exponent negatiu

  1. 2³·2⁻⁵ = 2³⁺⁽⁻⁵⁾.
  2. 3 + (−5) = −2.
  3. 2⁻² = 1/2² = 1/4.
Resultat: 1/4.
Exemple resolt

Base fraccionària

  1. (2/3)⁻².
  2. Invertim la base i fem positiu l’exponent: (3/2)².
  3. Elevem numerador i denominador: 9/4.
Resultat: 9/4.
Exemple resolt

Potència d’una potència

  1. (5⁻²)³.
  2. Multipliquem exponents: 5⁻⁶.
  3. Si volem exponent positiu: 1/5⁶.
5⁻⁶ = 1/15625.

⚠️ Errors habituals que convé evitar

⚠️

Pensar que a⁰ = 0

Per a a ≠ 0, a⁰ = 1.

⚠️

Fer a⁻³ = −a³

L’exponent negatiu indica recíproc: a⁻³ = 1/a³.

⚠️

Sumar exponents en una suma

a² + a³ no es pot transformar en a⁵.

⚠️

Oblidar els parèntesis del signe

(−2)² i −2² tenen resultats diferents.

✅ Què hauries de tenir clar

  • Calcular potències d’exponent zero i negatiu.
  • Treballar amb bases enteres i fraccionàries.
  • Aplicar correctament producte, quocient i potència d’una potència.
  • Controlar signes i parèntesis.
  • Detectar usos incorrectes de les propietats.
