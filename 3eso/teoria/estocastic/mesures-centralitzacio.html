🎯 Mesures de centralització

Mitjana, mediana i moda; taules de freqüències, dades agrupades i elecció de la mesura més representativa.

🟢 Practicar · Guiat🟠 Practicar · Autònom
Altres nivells:1r ESO2n ESO3r ESO

1. Què significa “centre” d’una distribució?

Les mesures de centralització resumeixen un conjunt de dades amb un valor que descriu la seva zona central. No són intercanviables: cadascuna respon a una idea diferent i pot reaccionar de manera diferent davant valors extrems.

2. Mitjana aritmètica

Mitjana: x̄ = (x₁ + x₂ + ··· + xₙ) / N

La mitjana reparteix la suma total de les dades de manera equilibrada entre tots els individus. Utilitza tota la informació numèrica, però per això mateix és sensible als valors molt grans o molt petits.

✏️ Notes 5, 6, 7, 8, 9

  1. Suma: 5+6+7+8+9 = 35.
  2. Nombre de dades: N=5.
  3. Mitjana: 35/5 = 7.

3. Mitjana amb taula de freqüències

Si un valor xᵢ apareix nᵢ vegades, no cal escriure’l repetidament: multipliquem valor per freqüència.

x̄ = Σ(xᵢ · nᵢ) / N

✏️ Nombre de llibres: 0, 1, 2, 3 amb freqüències 2, 5, 7, 1

  1. Total d’individus: N = 2+5+7+1 = 15.
  2. Suma ponderada: 0·2 + 1·5 + 2·7 + 3·1 = 22.
  3. Mitjana: 22/15 ≈ 1,47 llibres.

4. Mitjana estimada en dades agrupades

Quan només coneixem intervals, no disposem dels valors individuals. Aproximem cada interval per la seva marca de classe. El resultat és una estimació.

x̄ ≈ Σ(mᵢ · nᵢ) / N, on mᵢ és la marca de classe

✏️ Temps [0,10), [10,20), [20,30) amb freqüències 2, 5, 3

  1. Marques: 5, 15 i 25.
  2. Suma aproximada: 5·2 + 15·5 + 25·3 = 160.
  3. N = 10.
  4. Mitjana estimada: 160/10 = 16 minuts.
  5. És estimada perquè no sabem on són exactament les dades dins de cada interval.

5. Mediana

La mediana divideix les dades ordenades en dues meitats. Aproximadament el 50 % queda a cada costat. És més robusta davant valors extrems que la mitjana.

Si N és senar, prenem la dada central. Si N és parell, fem la mitjana de les dues dades centrals.

✏️ Dades 2, 4, 4, 7, 100

  1. Ja estan ordenades.
  2. N=5, així que la posició central és la 3a.
  3. Mediana = 4. El valor 100 no desplaça la mediana cap amunt com sí que fa amb la mitjana.

6. Moda

La moda és el valor o categoria amb freqüència més gran. Pot existir en variables qualitatives i quantitatives. Pot haver-hi una moda, diverses modes o cap valor clarament modal si totes les freqüències són iguals.

7. Quina mesura convé?

SituacióMesura que sol ser útilPer què
Dades simètriques sense extremsMitjanaUtilitza tots els valors.
Dades amb valors molt extremsMedianaÉs més robusta.
Categoria més freqüentModaÉs l’única de les tres que té sentit per a una variable qualitativa.
Dades agrupades en intervalsMitjana estimada / mediana aproximada segons la informacióHem perdut els valors individuals exactes.

⚠️ Errors habituals

  • Calcular una mitjana de categories codificant “vermell=1, blau=2...” sense significat numèric real.
  • Oblidar les freqüències i dividir Σxᵢ entre el nombre de files de la taula.
  • No ordenar les dades abans de trobar la mediana.
  • Dir que la mitjana agrupada és exacta: utilitza marques de classe i, per tant, és una aproximació.
