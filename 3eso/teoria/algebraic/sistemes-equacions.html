🔀 1. Què és un sistema?

Un sistema de dues equacions amb dues incògnites busca una parella (x,y) que compleixi les dues equacions alhora.

Una parella que només compleix una equació no és solució del sistema.

🔁 2. Mètode de substitució

Aïlla x o y en una de les equacions.
Substitueix aquesta expressió a l’altra equació.
Resol l’equació d’una sola incògnita.
Substitueix el valor trobat per obtenir l’altra incògnita.
Comprova la parella a les dues equacions.
y=7−x; 2x+y=11
2x+(7−x)=11 → x=4 → y=3

⚖️ 3. Mètode d’igualació

Aïlla la mateixa incògnita a les dues equacions.
Iguala les dues expressions obtingudes.
Resol l’equació resultant.
Recupera l’altra incògnita i comprova.
y=2x−1; y=8−x
2x−1=8−x → 3x=9 → x=3 → y=5

➖ 4. Mètode de reducció

L’objectiu és sumar o restar les equacions perquè desaparegui una incògnita. Si els coeficients no són oposats, multiplica abans una o totes dues equacions.

x+y=9
x−y=3
2x=12 → x=6 → y=3

📈 5. Interpretació gràfica

Cada equació lineal representa una recta.

Una interseccióUna solució.
Paral·leles diferentsCap solució.
Mateixa rectaInfinites solucions.

🌍 6. Modelitzar un problema

Defineix què representa x i què representa y.
Tradueix dues informacions independents en dues equacions.
Escull el mètode més eficient.
Resol i comprova.
Escriu la resposta amb unitats i significat.

⚠️ Errors habituals

  • Canviar un terme de membre sense mantenir l’equivalència.
  • Fer reducció sense multiplicar tota l’equació pel mateix nombre.
  • Trobar x i oblidar calcular y.
  • No comprovar la parella a les dues equacions.

✅ Comprova si ho has entès

1. Resol x+y=10 i x−y=2.
Sumant: 2x=12 → x=6; després y=4. (6,4).
2. Què representa gràficament la solució única?
El punt d’intersecció de les dues rectes.
3. Si dues equacions representen rectes paral·leles diferents, quantes solucions té el sistema?
Cap solució.
