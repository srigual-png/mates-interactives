Equacions de segon grau

Resoldre, comprovar i interpretar equacions on apareix x².

⚖️ 1. Forma general

Una equació de segon grau es pot escriure com:

ax² + bx + c = 0, amb a ≠ 0

Els nombres a, b i c són els coeficients. Abans de decidir el mètode, convé ordenar l’equació i identificar-los correctament, incloent-hi els signes.

🧩 2. Equacions incompletes

Quan falta b o c, sovint hi ha mètodes més directes que la fórmula general.

ax²+c=0
3x²−27=0 → x²=9 → x=±3
ax²+bx=0
2x²−6x=0 → 2x(x−3)=0 → x=0 o x=3

🧱 3. Resoldre factoritzant

Si podem escriure l’equació com un producte igual a zero, utilitzem la propietat del producte nul.

A·B=0 → A=0 o B=0
EXEMPLE PAS A PAS
x²−7x+12=0
(x−3)(x−4)=0
x−3=0 o x−4=0
x=3 o x=4

🧮 4. Fórmula general

x = (−b ± √(b²−4ac)) / (2a)
Ordena l’equació i identifica a, b i c.
Substitueix amb parèntesis, sobretot si b o c són negatius.
Calcula primer b²−4ac.
Calcula els dos casos del signe ±.
Simplifica i comprova cada solució.

🌍 5. Problemes i interpretació

En problemes d’àrees, nombres consecutius o dimensions, una solució algebraica pot no tenir sentit en el context.

Si una longitud dona x=5 o x=−8, matemàticament poden ser arrels de l’equació, però una longitud negativa no és admissible.

Comprovar té dues parts: verificar l’equació i verificar el significat real de la solució.

⚠️ Errors habituals

  • Oblidar una de les dues solucions en x²=k.
  • Identificar malament b quan el terme és −5x.
  • Oblidar el denominador complet 2a en la fórmula general.
  • Acceptar una arrel negativa en un problema de longitud sense interpretar-la.

✅ Comprova si ho has entès

1. Resol x²−16=0.
x=4 o x=−4.
2. Resol x²−5x+6=0.
x=2 o x=3.
3. Quins són a, b i c a 2x²−7x−4=0?
a=2, b=−7, c=−4.
