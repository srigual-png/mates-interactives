⭐ Ampliació · prepara 2n ESO

Ampliació per preparar 2n d’ESO: resol equacions amb la incògnita als dos membres i equacions amb parèntesis mantenint l’equivalència.

⭐ Aquest contingut és una ampliació per preparar 2n d’ESO. No forma part del Mode Examen de 1r ESO.

1. Equivalència 2. Dos membres 3. Agrupar 4. Parèntesis 5. Signes 6. Comprovar

⚖️ 1. Mantenir l’equivalència

La idea bàsica continua sent la mateixa: qualsevol operació que facis en un membre de l’equació l’has de fer també en l’altre.

L’objectiu és reunir els termes amb x en un membre i els termes independents en l’altre.

↔️ 2. x als dos membres

EXEMPLE
5x + 2 = 2x + 11
5x − 2x + 2 = 11
3x + 2 = 11
3x = 9
x = 3

🧩 3. Agrupar ordenadament

Elimina un dels termes amb x aplicant la mateixa operació als dos membres.
Agrupa els nombres a l’altre membre.
Quan quedi ax = b, divideix els dos membres per a.
Comprova el resultat.

📦 4. Equacions amb parèntesis

En el tipus treballat aquí, pots començar desfent el factor que multiplica el parèntesi.

EXEMPLE
3(x + 4) = 21
x + 4 = 7
x = 3
💡 Divideix els dos membres pel factor exterior abans de desfer la suma interior.

➕➖ 5. Control dels signes

Quan agrupes termes, no «canvien de signe per màgia»: estàs sumant o restant la mateixa quantitat als dos membres.

IDEA CLAU
5x + 2 = 2x + 11

Restar 2x als dos membres deixa 3x + 2 = 11.

✅ 6. Comprovar

Substitueix la solució a l’equació original, especialment quan hi ha x als dos membres o parèntesis.

COMPROVACIÓ
5·3 + 2 = 2·3 + 11 → 17 = 17 ✓

⚠️ Errors típics

  • Moure termes d’un membre a l’altre sense aplicar una operació equivalent.
  • Sumar els coeficients de x quan cal restar-los per agrupar.
  • Dividir només una part d’un membre.
  • En a(x + b) = c, oblidar que el factor a afecta tot el parèntesi.
  • No comprovar la solució a l’equació original.

✅ Comprova si ho has entès

1. En 5x + 2 = 2x + 11, què convé agrupar?
Els termes amb x en un membre i els nombres en l’altre.
2. Resol 4(x + 2) = 24.
x = 4.
3. Què manté una equació equivalent?
Fer la mateixa operació als dos membres.
4. Comprova x = 3 a 5x + 2 = 2x + 11.
17 = 17, per tant és correcte.

🧠 Resum essencial

  • Mantenir l’equivalència
  • x als dos membres
  • Agrupar ordenadament
  • Equacions amb parèntesis
  • Control dels signes
