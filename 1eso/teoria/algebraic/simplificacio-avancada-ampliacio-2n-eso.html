🧩 1. La regla no canvia

També en expressions més avançades, només es poden reduir els termes que tenen exactament la mateixa part literal.

x², x i els termes independents formen grups diferents.

² 2. Expressions amb x² i x

EXEMPLE
3x² − x² + 7x + 2x − 5
= (3x² − x²) + (7x + 2x) − 5
= 2x² + 9x − 5

🔤 3. Expressions amb x i y

Els termes amb x i els termes amb y no són semblants.

EXEMPLE
3x + 2y + x − y
= (3x + x) + (2y − y)
= 4x + y

🗂️ 4. Classificar abans d’operar

💡 Ordenar els termes per tipus redueix molt els errors de signes.

➕➖ 5. Respectar els signes

Quan agrupes, cada terme conserva el signe que tenia al davant.

EXEMPLE
5x² − 2x² − 3x + 7x = 3x² + 4x

🧠 6. Estratègia

Classifica els termes segons la seva part literal.
Agrupa els que siguin exactament semblants.
Opera només els coeficients de cada grup.
Reuneix els grups en una expressió final ordenada.

⚠️ Errors típics

  • Reduir x² i x com si fossin termes semblants.
  • Ajuntar termes amb x i termes amb y.
  • Canviar l’exponent quan sumes o restes termes semblants.
  • Perdre el signe menys d’un terme quan el reagrupes.
  • Multiplicar coeficients quan l’operació és una suma o una resta.
