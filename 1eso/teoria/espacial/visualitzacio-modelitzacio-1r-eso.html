🧩 Visualització i modelització

Utilitza figures geomètriques per entendre multiplicacions, potències, arrels, fraccions i patrons numèrics.

🧩 1. Rectangles com a models de multiplicació

Un rectangle organitzat en files i columnes permet visualitzar un producte.

files × columnes = nombre total de quadradets
EXEMPLE

4 files i 7 columnes representen 4×7=28.

✂️ 2. Visualitzar la propietat distributiva

Si dividim un rectangle en dues parts, podem calcular l’àrea de tot el rectangle sumant les àrees parcials.

(a + b) · h = a·h + b·h
EXEMPLE
(3+5)·4 = 3·4 + 5·4 = 32

⬜ 3. Quadrats, potències i arrels

Un quadrat de costat n té n×n unitats quadrades.

Potència
àrea = n²
Arrel quadradaSi coneixem l’àrea A, el costat és
√A
EXEMPLE

Àrea 81 → costat √81=9.

🔢 4. Patró dels nombres senars

Afegint capes amb nombres senars consecutius es van completant quadrats.

1 + 3 + 5 + … + (2n−1) = n²
EXEMPLE
1+3+5+7 = 16 = 4²

½ 5. Producte de fraccions amb un rectangle

Quan representem una fracció de l’amplada i una altra fracció de l’alçada, la zona que se superposa representa el producte de les dues fraccions.

EXEMPLE
1/3 × 2/5 = 2/15

🧠 6. Modelitzar abans de calcular

Identifica quina figura pot representar la situació.
Relaciona cada dimensió amb una quantitat numèrica.
Interpreta visualment què significa l’operació.
Comprova que el resultat coincideix amb el model geomètric.

⚠️ Errors típics

  • Comptar files i columnes sumant-les en lloc de multiplicar-les.
  • Confondre n² amb n×2.
  • Buscar √A dividint A entre 2.
  • No simplificar el producte de fraccions quan es pot.
  • Veure el dibuix com a decoració i no relacionar-lo amb l’operació que representa.
