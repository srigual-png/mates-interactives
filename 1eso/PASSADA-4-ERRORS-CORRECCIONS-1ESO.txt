PASSADA 4 · ERRORS I CORRECCIONS · 1r ESO
==========================================

Objectiu
--------
Homogeneïtzar el sistema d'errors dels cinc sentits sense modificar teoria, Mode Examen ni gestió de temes/progrés.

Estàndard aplicat
-----------------
- La teva resposta.
- Resposta correcta.
- 🔎 Què convé revisar.
- 📘 Resolució pas a pas.
- Error persistent.
- Eliminació individual.
- Esborra tots els errors.
- Últims errors visibles dins del bloc.
- Errors de pràctica, examen i problemes oberts registrats amb el context original.

Retocs principals
-----------------
- S'ha afegit el camp review als errors nous, derivat de les pistes/guia de l'exercici.
- Si un error antic no té review o guide, es mostra un recordatori pedagògic genèric en lloc de deixar el bloc buit.
- La correcció immediata després d'un error incorpora 'Què convé revisar' abans de la resolució.
- La pantalla d'Errors guardats mostra també 'Què convé revisar'.
- Els errors recents del bloc mostren resposta donada, correcta, revisió i explicació quan està disponible.
- Numèric i Estocàstic s'han reforçat especialment perquè mostraven menys context que els altres sentits.
- Etiquetes d'esborrat homogeneïtzades amb 'Esborra...'.

Validació
---------
- 5/5 fitxers sentit-*.html: sintaxi JavaScript OK.
- 5/5: camp review desat.
- 5/5: 'Què convé revisar' implementat.
- 5/5: eliminació individual d'errors.
- 5/5: esborrat global d'errors.
- 5/5: errors recents dins del bloc.
- 5/5: resolució pas a pas disponible per als errors nous.
- Comparació amb P3: només s'han modificat els cinc sentit-*.html.
- index.html, teoria i informes P1/P2/P3: intactes.
